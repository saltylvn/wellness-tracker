WELLNESS TRACKER · WEB APPLICATION

An iPhone-first, installable web app for nutrition, lifting, cardio and weight, with AI calorie estimates from a photo. Designed, built, secured and shipped end to end: 52 pull requests in 3 weeks, in daily use.

▶ Try the demo: wellness-tracker-virid.vercel.app github.com/saltylvn/wellness-tracker
What it does

🍽️ Nutrition

Photo or text → Gemini estimates calories and macros, always editable. Calorie ring, macro goals, water, saved foods.

🏋️ Fitness

Weekly lift / cardio plan, scroll-wheel set logging, supersets, distance goals, and a #1000club 3-rep-max tracker.

⚖️ Weight

Daily weigh-ins, a chart with a projected goal date, and a one-line AI coaching note.

🔥 Streaks

Food and workout streaks on the phone's local date, so they never break at midnight UTC.

How it's built

📱 iPhone PWA

  • Home-screen app
  • Photo resized on device (768px)
  • No database or AI code shipped to the browser
→

▲ Next.js 16 on Vercel (Node 24)

  • Proxy: session refresh, auth gate, per-request CSP nonce
  • Server Components render pages; 2 rounds of parallel queries
  • Server Actions for every write, with sign-in and input checks
  • AI route: validate → daily limit → raced model chain → validate reply
→

🐘 Supabase Postgres

  • RLS on all 13 tables
  • Triggers + RPCs with advisory locks
  • Google sign-in (OAuth)

✨ Google Gemini

  • JSON-schema output
  • Fastest-first, hedged at 1.5 s
🔒 Trust boundary: the browser only talks to the app. Secrets, database access and AI calls stay server-side; every AI reply is validated as untrusted input.
