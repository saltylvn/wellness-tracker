WELLNESS TRACKER · WEB APPLICATION

An iPhone-first, installable web app for lifting, cardio, nutrition and weight, built end to end and in daily use: 52 pull requests in 3 weeks. Shown: the Fitness tracker on the live app, with demo data.

The fitness tracker
1

Swipe to log a set

iOS-style scroll wheels: swipe up or down to set the weight (2.5 lb steps) and reps, then one tap adds the set.

2

Progress at a glance

Last time, today's sets and your heaviest lift on every exercise; weight defaults to what you used last.

3

Your week, one tap

Toggle lift or cardio per day; each tap saves itself, and exercises survive a switch.

4

Streak & calendar rings

A green ring on every trained day; a planned rest day never breaks the streak.

5

Training structure

Sauna and stretch checks, supersets with no rest, and 3–5 min rest reminders.

6

#1000club & cardio goals

Bench + deadlift + squat 3-rep maxes toward 1,000 lb; weekly run, cycle and swim goals.

Engineering behind it
  • Scroll wheels on native CSS scroll-snap (no JS animation), with memoized rows
  • 2 database round trips per page, guarded by a performance test
  • Server Actions for every write, with sign-in and input checks
  • Row-level security on all 13 Postgres tables
  • 232 automated tests; CI gates every PR in ~30 s
  • Strict nonce CSP, CodeQL, secret scanning, protected main
